📋 EDITING GUIDE:
═══════════════════════════════════════════════════════════════════════════

Product Card Location: index.html (around line 135)

Each product card looks like:
┌──────────────────────────────────────────────┐
│ <div class="product-card">                   │
│   <img src="./assets/images/product1.jpg">   │
│   <h3>Product Title</h3>                     │
│   <p>Product description</p>                 │
│   <span>✓ Benefit 1</span>                   │
│   <span>✓ Benefit 2</span>                   │
│   <span>✓ Benefit 3</span>                   │
│   <a href="https://fktr.in/YOUR_CODE">      │
│     Check Price on Flipkart                  │
│   </a>                                       │
│ </div>                                       │
└──────────────────────────────────────────────┘

Just replace:
  • product1.jpg → your_image.jpg
  • Product Title → Your actual title
  • Product description → What the product is
  • Benefits → Actual benefits/features
  • YOUR_CODE → Your Flipkart affiliate link
